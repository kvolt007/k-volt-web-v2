# K-Volt Web V2

Versión 2 de la web de K-Volt para comparar contra la V1.

## Objetivo

Evolucionar de una landing institucional a una web de captación local con tres pilares:

- Electricidad para hogares.
- Electricidad para empresas / PYMEs.
- Climatización residencial (aires acondicionados).

## Enfoque

- SEO local para Rosario y Gran Rosario.
- Copy orientado a problemas reales del cliente.
- Arquitectura preparada para crecer a páginas por servicio.
- CTAs claros a WhatsApp.
- Sección de obras nuevas.
- Módulo separado de climatización residencial.
- Sin afirmar matrícula ni certificaciones no verificadas.

## Pendientes antes de producción

- Cargar WhatsApp, teléfono y email reales en `script.js`.
- Definir dominio definitivo.
- Agregar logo oficial y fotos reales de trabajos.
- Integrar reseñas reales de Google cuando estén disponibles.
- Crear páginas SEO individuales por servicio en una siguiente etapa.
